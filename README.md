
# Mountain Website

## Project Description
This project is a simple webpage created using HTML and CSS.
It displays a mountain image as a full-screen background.

## Project Files
- index.html: Contains the HTML structure and CSS styling.
- landing.jpg: The mountain background image.
- README.md: Explains the project.

## Technologies Used
- HTML
- CSS

## How to Run
1. Download the project files.
2. Open index.html in a web browser.
3. The mountain image will appear on the screen.
